# sol

## tabs

### interior colors

#### features

- be able to pick any color you want
- adjust brightness

### interior modes

#### features

- map 3 modes to a specific color

### interior animations

#### features

- turn on/off sport mode flash
- turn on/off shift indicator
- rgb rainbow mode
- hazard modes from upstream
- speed based interior color

### exterior control

#### features

- control all individual exterior lamps
- be able to do this while moving

### exterior animations

#### features

- strobe mode
- light show
- cop mode
- all of these last until the user turns it off
